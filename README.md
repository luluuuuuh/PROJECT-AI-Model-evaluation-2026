# PROJECT-AI-Model-evaluation-2026
This project tests to what extent Claude Sonnet 5.5 identifies anti-elite rhetoric in 44 tweets by George Simion from his 2025 campaign, against my hand-coded labels. It agreed on 81.8% (baseline 56.8%), mostly missing positives (recall 0.63). A reworded prompt changed two labels (77.3% agreement).
